## namespace（P1）三语言完成并推送（提交 c500733 / 7177bc1，已 push origin/main）

tx-cpp / tx-dotnet / tx-python 三个 worker 派下去后全部被 **429**（15:42 重置）打断，各留半成品：
C++ 只做了 producer、.NET 只加了个字段、Python 只加了 latency/metrics 骨架。主会话接手补全。

- **C++/.NET 完整 namespace**：新增 `NamespaceUtil`（`cpp/include/rocketmq/common/namespace_util.h`、
  `dotnet/.../Common/NamespaceUtil.cs`）；分隔符 `%`，`%RETRY%/%DLQ%` 在命名空间**之外**（`%RETRY%NS%GID`），

  fetchPublishMessageQueues 都包装 topic；consumer 在 subscribe 包装 topic、在 start 里**一次性**包装
  消费组（与 Java 相同，之后心跳/rebalance/位点/锁/回投都用 `ns%group`）、还原 `%RETRY%` 时剥掉命名空间。
- **真机新增 S8**：带 namespace 的生产/消费在 `<ns>%<topic>` 收发成功；不带 namespace 的消费者订阅同名
  裸 topic 收不到（隔离证明）。
- **验证**：真机 `run_redelivery_live.sh all` → Python **21/0**、C++ **19/0**、.NET **19/0**（RC=0）；
  ctest 8/8、xunit 46/46、pytest 147/4；三侧 **0 warning**。
- **Python 故障规避 + metrics**（7177bc1）：`latency.py`/`metrics.py` 原本是死代码，已接入
  `send()`/`send_oneway()` 的选队列（available→reachable→轮询）与 RT/计数记录；默认关闭（同 Java）。
