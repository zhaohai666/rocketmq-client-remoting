### 关键语义（跨端一致，别再改）
- 开关关闭时 `subscription` 字段**根本不进 extFields**（Java `subExpression=null` +
  `makeCustomHeaderToNet` 跳过 null）。四端统一按「SUBSCRIPTION 位是否置位」决定该字段是否上线。
- broker 侧 `PullMessageProcessor:396-418`：**位关时走 else 分支**，从 `ConsumerManager` 查心跳注册的
  订阅，查不到回 `SUBSCRIPTION_NOT_EXIST`。所以关掉后 broker 能否过滤取决于心跳已注册 ——
  与 Java 默认行为一致，但**真机回归要留意首拉与心跳的先后**（P6 真机验证时顺带确认）。
- `findBrokerAddressInSubscribe` 的 `isSlave` 一律按**命中的 id** 判（不是传进来的 brokerId），
  所以「brokerId=3 从节点缺席 → 回退 master」时 COMMIT_OFFSET **不清**。
